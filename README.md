# Oracom Group — Independent Homepage Redesign

Responsive single-page React redesign concept for Oracom Group.

## Run locally

Requirements: Node.js 18+

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Stack
- React + Vite
- Custom responsive CSS
- Framer Motion (scroll reveal)
- Lucide React (icons)

## Sections
- Announcement bar and sticky responsive navigation
- Hero / brand positioning
- Company facts and statistics
- Services overview
- About Oracom
- 21-brand ecosystem
- East African footprint
- Brand statement
- Contact call-to-action and footer

## Assets and content
This concept currently uses externally hosted Unsplash and Wikimedia imagery as visual placeholders. The Oracom logo is represented as editable text/monogram so the project works without a downloaded logo file. Replace these with approved, locally stored company assets before publishing. Company facts and brand descriptions are based on publicly available Oracom Group website content and should be verified before public/commercial use.

This is an independent redesign concept, not an official Oracom Group website and is not affiliated with or endorsed by Oracom Group.
