# Oracom Group — Independent Homepage Redesign

Responsive single-page React redesign concept for Oracom Group.

## Run locally

Requirements: Node.js 18+

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Stack
- React + Vite
- Custom responsive CSS
- Framer Motion (scroll reveal)
- Lucide React (icons)

## Sections
- Announcement bar and sticky responsive navigation
- Hero / brand positioning
- Company facts and statistics
- Services overview
- About Oracom
- 21-brand ecosystem
- East African footprint
- Brand statement
- Contact call-to-action and footer

## Assets and content
The official Oracom logo is stored locally at `public/images/logo.png`. The About and Contact sections use illustrative African business/team photographs hosted by Pexels: [Lagos team collaboration](https://www.pexels.com/photo/team-collaboration-meeting-in-lagos-office-30689114/) and [African women collaborating in an office](https://www.pexels.com/photo/office-team-having-a-meeting-3869649/). These are stock photographs, not representations of Oracom staff, offices or projects. Replace them with company-approved photographs if Oracom provides them. Company facts and brand descriptions are based on publicly available Oracom Group website content and should be verified before public/commercial use.

This is an independent redesign concept, not an official Oracom Group website and is not affiliated with or endorsed by Oracom Group.
